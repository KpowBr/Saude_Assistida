# 🥗 Saúde Assistida

Painel web completo e responsivo desenvolvido para o acompanhamento de saúde, controle de peso, rotina de treinos, diário de bordo e planejamento nutricional.

## 🚀 Funcionalidades
- **Visão Geral:** Indicadores automáticos de peso, ritmo e metas.
- **Diário Interativo:** Calendário com registro de humor, sono e anotações diárias.
- **Treinos:** Histórico de treinos e biblioteca de exercícios guiados.
- **Evolução Corporal:** Gráficos de progresso com cálculo automático de déficit calórico e composição corporal.
- **Nutrição:** Controle de refeições e registro de desvios diários.
- **Multi-usuários & Backup:** Sistema de cadastro de múltiplos perfis com exportação/importação de dados em JSON (`localStorage`).
